**Owner:** Meera Kannan · **Last updated:** 2026-11-09 · **Status:** On `main`. Reviewer feedback (`MeeraFeedback.md`) is being worked through one item at a time; see Open items.

## What this is

An MkDocs (Material) site for the hands-on **Coding Agents for Test** workshop. Its theme and conventions are copied from <a href="https://uipath-practice.github.io/SoftwareTestingCourse/" target="_blank">software-testing-ilt-guide</a>. See [CLAUDE.md](CLAUDE.md) for the content standards.

- **Publishes to:** `https://uipath-practice.github.io/CodingAgentsTestingWorkshop/`, through `.github/workflows/deploy.yml` on every push to `main`. Push to `origin` (uipath-practice) only.
- **Old site:** `https://meera-uipath.github.io/Coding-Agents-For-Test-Workshop/` now redirects to the new URL, keeping the page path. Its repo is the `meera` remote. Don't push to it, or the redirect is overwritten.
- **Preview locally:** `start-guide.bat` (uses `.venv`, which has `mkdocs-material` installed), then open http://127.0.0.1:8000

## Decisions

- **The trainer provides a dedicated, new tenant and the group permissions.** Learners need the **Project Creator** tenant role to import the `.tmh` (step 1); the importer becomes **Project owner** automatically, which covers the Default Folder (step 1) and the Test Tier custom field (step 4).
- **Each learner creates a personal folder in step 2**, as the trainer guides them, and assigns their machine (with an **App Testing** or **Testing** runtime) to it. It's set as the project's **Default Folder** (Project Settings → Automation tab). Which folder Studio publishes to doesn't matter.
- **Delegate is the only agent.** It ships with the latest Studio STS, with the `uip` CLI and the `uipath-testcloud` skill built in. Its consumption is included in the UiPath user license. The Claude Code / Codex section was removed on 2026-10-29; it's in git history before that date.
- **Delegate setup (Installation Guide step 2):** open it from the top ribbon, set **Work profile** to **QA / Testing** (Settings → Behavior preferences), then **+ New**. Approval mode is in **Settings → Security**: Cautious / Adaptive (recommended, with a Smart approvals toggle) / Full access.
- **Built-in agents** are named **Evaluate Requirement Quality** (step 3) and **Generate Test Cases** (step 4). The requirement is **Submit Loan Request**.
- **The project file** is `docs/assets/Files/Agentic Testing Workshop - Sample Test Manager Project.zip`, re-exported by the owner on 2026-11-10 (project "UiBank Project", prefix `UIBWS`): 1 requirement (Submit Loan Request), 6 test cases (all with steps, all in the set), 1 test set (UiBank Smoke Test Set, static), 17 past executions, no custom fields, no Coding Agent WS label. Learners rename the project and prefix with their own name.
- **Test cases are automated only with Autopilot for Testers in Studio (step 6).** Delegate builds the Object Repository. Learners automate **every** test case they chose in step 3, then check them by name with Delegate after publishing (links only exist once the project is published). Step 6 creates a new Test Automation project; there's no starter project.
- **No workshop label (since 2026-11-10).** Learners choose **at least 3** test cases on Submit Loan Request, generated or existing, note their names (step 3), and automate all of them (step 6). The Coding Agent WS label is gone. One becomes the data-driven test, which fails on one row by design; learners never build a failing test case.
- **The test case with test data is the failing one (step 6, Attach test data).** The second row of `UiBankLoanData.csv` (age 32, income 15,000, loan 5,000, 3 years) expects **FALSE**, but the requirement approves it, so the step 8 report has a real failure. Learners no longer change an input by hand.
- **Loan lookup (step 4) is optional** and labelled **Delegate**; it isn't added to the test set and isn't automated. Step 4's Test Tier box says Test Tier doesn't add test cases to UiBank Smoke Test Set.
- **Delegate remembers the project.** Step 1's first prompt lists the learner's projects (asks which one if there are several) and remembers it; later prompts say "my project", with no project key placeholder.
- **Step 7 (since 2026-11-10):** no new set. Learners open the imported **UiBank Smoke Test Set** (static; holds the 6 existing Submit Loan Request test cases) and use **Static Assignment** to add their new automated test cases, then Configure Automation. Step 8 triggers this set; Delegate (owner's check) triggers only its automated test cases, and the prompt lists manual ones as not run. Runs triggered from Test Manager use the Default Folder, so they run on the learner's machine.
- **Step 8:** the report content, save questions and PDF follow-up come from the Fusion PDF. Routines are a read-through, not hands-on.
- Python and the .NET 8 SDK are left out of the prerequisites.
