# 02. Link the Project to Your Folder

To run tests automatically, Test Manager needs to know which **Orchestrator folder** to use. Link your project to the personal folder you set up in [Prerequisites](../module-0-prerequisites/index.md#orchestrator-folder-and-robot).

!!! example "It's your turn now!"
    In your Test Manager project, go to **Project Settings**, open the **Automation** tab, set **Default Folder** to your personal folder, and click **Save**.

!!! failure "Skipped this step?"
    Runs fail with `HTTP 400: Please assign folder to project level before executing testcases.`

## Nice work!

Your project is linked to a folder with a robot to run its tests.
